# SpatialToM project page

A minimal static academic homepage for **SpatialToM: Modeling Multi-Agent Theory of Mind for Embodied Spatial Intelligence**.

Repository: `SpatialToM-Bench/spatialtom-bench.github.io`

Site address: https://spatialtom-bench.github.io/

## Publish

Upload the contents of this folder to the repository root on `main`: `index.html`, `style.css`, `.nojekyll`, and `assets/`.

In **Settings → Pages**, select **Deploy from a branch → main → / (root)** and save.

## Preview and edit

Open `index.html` directly in a browser. There are no dependencies or build steps.

The page contains the title, author list, affiliations, overview figure, abstract, and resource availability labels. Edit `index.html` for text and links, and `style.css` for layout.

Han Yin, Yining Hong, and Jiageng Liu are marked as equal contributors. Yejin Choi shares affiliation 1, Stanford University. Author order and other affiliations follow the supplied screenshot.
